# KbdReset

A small utility that releases all keyboard keys. It can help fix stuck keys and keyboard input issues.


## Build

Open `KbdReset.sln` in Visual Studio and choose **Release > Build Solution**.


## 

There was a similar program I used in the past, but I couldn't find it anymore.

I wrote this small replacement in C# using .NET Framework. It supports 32 and 64 bit systems. 

ARM support requires .NET Framework 4.8.1
